Vault Bookmarks tools

Check links

Asks each site if the page still exists (a HEAD request, then GET when the site refuses it). Chrome asks once for permission to reach websites; nothing else leaves your machine, and no note is changed until you choose. A page that answers 404 or 410, or a site that does not answer at all, is proposed as Dead; a link marked Dead that answers again is proposed as Active.

      Import Chrome bookmarks

      Reads your Chrome bookmarks (Chrome asks for permission once) and writes one note per link, skipping links the folder already holds. Pick the folders to import.
